# Сайт с переключением тем

## 📌 Описание проекта

Адаптивный веб-сайт с возможностью переключения между светлой и темной темами. Проект разработан с использованием подхода Desktop first и полностью адаптирован под различные устройства.

## 🛠 Стек технологий

- HTML5 - семантическая разметка
- CSS3 - современные стили
- Flexbox - гибкая организация элементов
- Grid Layout - сложные сетки
- CSS-переменные - управление темами
- Медиа-запросы - адаптивная верстка

## ✨ Реализованная функциональность

- Адаптивный дизайн (Desktop first)
- Переключение светлой/темной темы
- Использование CSS-переменных
- Гибкая сетка на Flexbox и Grid
- Оптимизированные медиа-запросы
- Кроссбраузерная совместимость

## 🚀 Как запустить проект

Клонируйте репозиторий

```
git clone https://github.com/Krylova-tan/verstka_theme-switch.git
```

Откройте файл index.html в браузере
